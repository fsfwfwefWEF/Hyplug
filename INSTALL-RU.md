# BodyCam — камера от лица, в которой видно всё тело

Мод заменяет SimpleMenu в этом репозитории. Инструкция написана для человека,
который не программирует: читайте сверху вниз.

---

## Что делает мод

Обычный вид от первого лица в Hytale показывает только руки. С этим модом камера
остаётся на уровне глаз, но клиент рисует персонажа целиком: посмотрите вниз —
увидите туловище и ноги, в руках видна модель предмета, как её видят другие игроки.

- Камера включается **сама**, как только игрок зашёл на сервер.
- Каждый игрок может выключить её у себя командой `/bodycam`.

### Команды (доступны всем игрокам)

| Команда | Что делает |
|---|---|
| `/bodycam` | включить / выключить |
| `/bodycam on` / `/bodycam off` | включить / выключить явно |
| `/bodycam forward 0.2` | сдвинуть камеру вперёд по взгляду (минус — назад), от -1 до 1 |
| `/bodycam up 0.1` | сдвинуть камеру вверх (минус — вниз), от -1 до 1 |
| `/bodycam reset` | вернуть сдвиги к нулю |
| `/bodycam info` | показать текущие настройки |

Короткие имена: `/bc` и `/камера`.

Настройки хранятся, пока работает сервер. После перезапуска сервера у всех снова
включена камера со сдвигами по умолчанию.

## Установка

1. Скачайте `BodyCam-1.0.0.jar`: <https://github.com/ayaft1445-eng/hytaleplug/releases/tag/bodycam-latest>
   (файл внизу страницы, в разделе **Assets**).
2. Остановите сервер.
3. Удалите из папки `plugins` (или `mods`) старый `SimpleMenu-*.jar`.
4. Положите туда `BodyCam-1.0.0.jar`.
5. Запустите сервер. В консоли должна появиться строка:
   `[BodyCam] Loaded. Type /bodycam in chat to toggle the body camera.`
6. Зайдите на сервер — камера уже включена.

## Как настроить под себя

Сначала попробуйте без сдвигов. Если при взгляде вперёд видно голову
изнутри (волосы, шлем, край лица), сдвиньте камеру чуть вперёд:

```
/bodycam forward 0.15
```

Подбирайте в пределах **0.1–0.35**. Чем больше сдвиг, тем меньше мешает голова,
но при взгляде вниз камера уходит ниже и ближе к груди.

Если камера кажется слишком низкой или высокой — `/bodycam up 0.1` или `/bodycam up -0.1`.

Когда найдёте удобные числа, их можно сделать значениями по умолчанию для всех:
файл `src/main/java/dev/hytalemodding/bodycam/BodyCamera.java`, строки
`DEFAULT_FORWARD` и `DEFAULT_UP`. Там же `ENABLED_BY_DEFAULT = true` — поставьте
`false`, если камера не должна включаться сама при входе. После правки нужно
заново собрать jar (любой пуш в репозиторий собирает его в GitHub Actions
и обновляет релиз).

## Что важно знать

- **Это серверный приём, а не клиентский мод.** Сервер не умеет прятать на клиенте
  одну только голову персонажа, поэтому голову убирают сдвигом камеры вперёд
  (`/bodycam forward`).
- **Анимации рассчитаны на вид сбоку.** Удары, стрельба из лука и бег при взгляде
  вниз могут выглядеть непривычно.
- **Пока мод включён, камерой управляет сервер.** Клавиша смены вида может
  перестать работать. Вернуть обычную камеру — `/bodycam off`.

## Если что-то не работает

| Что видно | Почему так | Что делать |
|---|---|---|
| В логе нет строки `[BodyCam]` | Файл не в той папке или не та версия сервера | Проверьте папку `plugins`. Мод рассчитан на сервер 0.6.x |
| `/bodycam` — «команда не найдена» | Мод не загрузился | Вернитесь к пункту 5 установки |
| Камера обычная после входа | Кто-то выключил её командой | `/bodycam on` |
| Видно голову изнутри | Камера стоит внутри модели головы | `/bodycam forward 0.2` |
| Камера отстаёт или трясётся | Лаг сети | Пришлите лог сервера — поправлю |
